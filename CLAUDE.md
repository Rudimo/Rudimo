# Правила работы в этом репозитории

## Формат выдачи результатов (ВАЖНО)

Для любых задач, связанных с проектами владельца — **Wavetech Software (WTsoftware), postim.life, postWorld** — действует постоянное правило:

1. **Результат всегда отдавать картинкой (PNG).** Любой финальный артефакт (постер, отчёт, статус, превью) рендерится в изображение.
2. **Присылать сразу по завершении.** Как только задача готова — немедленно отправлять изображение пользователю в чат (через доставку файла), не дожидаясь отдельной просьбы.
3. **Делать это после каждой такой задачи/вопроса**, без напоминаний.

> Примечание о доставке: в текущей среде отправка идёт в этот чат как файл-изображение.
> Рассылка через продакшн-бот postim.life возможна только из репозитория/инфраструктуры postim.life
> (здесь подключён только репозиторий `rudimo/rudimo` и нет токена бота). Когда работа идёт в репозитории
> postim.life — использовать его существующий бот/токен для фактической отправки.

## Контекст проектов

- **Wavetech Software** — компания/бренд владельца.
- Команда оформляется как «совет директоров» (board of directors) — см. постеры/брендинг.
